# 🏨 Hotel Kothic

A modern and interactive hotel website built using **HTML, CSS, and JavaScript**. The project provides a visually appealing interface for showcasing hotels, rooms, customer reviews, and contact information.

The website focuses on creating a smooth and engaging user experience using modern front-end techniques, animations, sliders, and dynamic content.

## ✨ Features

* 🏨 Modern hotel landing page
* 🖼️ Interactive hero image slider
* 🏠 Hotel availability/listing section
* ⭐ Customer feedback and testimonials
* 🎨 Custom cursor effects
* ✨ Smooth animations using GSAP
* 📱 Responsive and user-friendly interface
* 🧭 Navigation functionality
* ⏳ Loading animation
* 📞 Contact information section
* 🔗 Social media links
* 📋 Useful navigation links
* 🎯 Clean and visually focused UI

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic markup
* **CSS3** – Styling, layouts, animations, and visual design
* **JavaScript** – Interactivity and dynamic functionality
* **Swiper.js** – Hero/image slider
* **GSAP** – Smooth animations and transitions
* **Remix Icon** – Social media and interface icons
* **Font Awesome** – Contact and utility icons



## 🎯 Main Sections

### Hero Section

The hero section uses **Swiper.js** to create an interactive image slider that introduces the hotel website with a visually attractive presentation.

### Hotel Availability

The hotel listing section displays available hotels/rooms dynamically through JavaScript. Multiple card containers are used to organize and present hotel information.

### Customer Feedback

A testimonial section allows visitors to view feedback from previous customers.

Example testimonials include reviews about:

* Hotel location
* Room cleanliness
* Family-friendly facilities
* Spacious rooms
* Overall customer experience

### Footer

The footer contains:

* About Us
* Useful Links
* Social Media Links
* Address
* Phone Number
* Email Address
* Copyright information
